# LinkedIn Profile Optimization — React Native Developer

How recruiters actually find people: LinkedIn Recruiter keyword/Boolean search, e.g.
`("React Native" OR "React-Native") AND (TypeScript) AND (iOS OR Android) NOT Flutter`,
filtered by title, location, years, "Open to Work", and skills. If the words aren't on your profile, you don't appear.

Search weight (approximate, from 2026 practitioner guides): **Headline > current job title > Skills > About > Experience descriptions**.

---

## 1. Headline (220 chars) — highest weight

Formula: **Role keyword | Specialty / proof | Stack keywords | (optional) what you want**

Rules
- Put "React Native" in the first ~40 characters (it's what shows in search results and comments).
- Include 1 alternate title recruiters search: "Mobile Engineer", "iOS & Android".
- 1 proof point beats 5 adjectives.
- No "Aspiring", no "Seeking opportunities" as the lead, no emoji strings.

Templates
- `React Native Engineer | Shipped 6 iOS & Android apps (500K+ downloads) | TypeScript · Expo · New Architecture · Reanimated`
- `Senior Mobile Engineer (React Native) | Performance & animations | Cut app startup 40% | TypeScript, Expo/EAS, Native Modules`
- `React Native Developer | Fintech & e-commerce apps | Expo, Redux Toolkit/Zustand, React Query | Open to remote roles`
- Junior: `React Native Developer | TypeScript · Expo · Firebase | 2 apps live on Play Store & App Store | Building in public`

## 2. Photo, banner, URL, name

- **Photo:** face fills ~60% of frame, plain background, good light, you smiling, recent. Real photos outperform stock everywhere on LinkedIn.
- **Banner (1584 × 396 px, 4:1):** a value statement + visual proof. E.g. left: "I build fast, smooth React Native apps" ; right: 2–3 phone mockups of your apps, or store badges. Keep text out of the bottom-left (photo covers it on mobile). Don't put the URL there.
- **Custom URL:** `linkedin.com/in/firstname-lastname` or `firstname-reactnative`. Put it on resume, GitHub, email signature.
- **Pronouns / name pronunciation:** optional; fine to add.
- **Location:** set to the city you're targeting, or the metro if remote-hunting in a region. Recruiters filter by location.
- **Contact info:** email + portfolio + GitHub. Recruiters with no InMail credits will email you.

## 3. Open to Work — decision

Fill these regardless: job titles (up to 5: React Native Developer, React Native Engineer, Mobile Engineer, Mobile Developer, Frontend Engineer), workplace types, locations, start date, employment types.

| Situation | Choose |
|---|---|
| Employed, discreet | **Recruiters only** (hidden from people at your company, not guaranteed) |
| Unemployed / laid off / student | **Public green frame** is usually net-positive: ~40% more recruiter InMails per LinkedIn data; also activates your network. ~1 in 5 hiring managers say it reduces interest — accept that trade when actively searching. |
| Freelance | Use "Providing services" instead/also |

Downside of public frame: more scam "recruiters". Never pay for anything, never install apps/"tests" from unknown parties, verify the company domain.

## 4. About section (2,600 chars; ~first 3 lines show before "see more")

Structure (3 short blocks + a skills line + CTA):
1. **Hook + what you build:** "I build React Native apps people actually keep on their phones — 6 shipped to the App Store and Play Store, the largest with 250K MAU."
2. **Proof (2–3 bullets with numbers):** perf wins, launches, scale, ownership (release pipeline, OTA updates, native modules).
3. **How you work / what you care about:** e.g. performance budgets, accessibility, testing, shipping weekly with EAS.
4. **Keyword line:** `Stack: React Native (New Architecture), TypeScript, Expo / EAS, React Navigation / Expo Router, Redux Toolkit, Zustand, TanStack Query, Reanimated, Jest, Detox/Maestro, Firebase, REST/GraphQL, Swift/Kotlin basics, CI/CD.`
5. **CTA:** "Open to Senior React Native roles (remote, EU/US time zones). Email: …"

Use first person, short paragraphs, and plain bullets (•). Avoid "passionate", "guru", "ninja".

## 5. Experience — each role

- Title field: use the searchable title. If your official title is "Software Engineer II" but you did RN, write `Software Engineer II (React Native)`.
- 3–6 bullets per role, same formula as resume: **Action verb + what you built + how (tech) + measurable result**.
- Attach skills to each role (LinkedIn lets you link up to ~5 skills per position) — this reinforces skill relevance.
- Add media: app store links, demo video, screenshots.
- Freelance/side projects with real users can be a role ("Independent Mobile Developer").

Good RN bullets:
- `Migrated app to React Native New Architecture (Fabric + TurboModules) and Hermes; cold start down 38% (2.9s → 1.8s on mid-range Android).`
- `Rebuilt the feed with FlashList and memoized cells; dropped JS-thread frame drops from 18% to 3% while scrolling.`
- `Set up EAS Build + EAS Update pipeline; release cadence went from monthly to weekly, hotfixes shipped OTA in < 1 hour.`
- `Wrote a Kotlin/Swift native module for BLE device pairing used by 40K users.`
- `Raised crash-free sessions from 97.1% to 99.6% via Sentry triage and error boundaries.`

## 6. Skills (up to 50)

- Pin / top: React Native, TypeScript, JavaScript, Mobile Application Development, iOS & Android Development (or Expo).
- Then: React, Redux / Redux Toolkit, Zustand, TanStack Query, React Navigation, Expo Router, Reanimated, Gesture Handler, Jest, React Native Testing Library, Detox, Maestro, Firebase, GraphQL, REST APIs, Node.js, Git, CI/CD, Fastlane, App Store Connect, Google Play Console, Swift, Kotlin, Performance Optimization, Accessibility, Agile.
- Get endorsements for the top 5 from colleagues (profiles with endorsements get far more recruiter views). Take LinkedIn skill assessments only if you'll pass top 30%.

## 7. Featured section (pick 3–5)

Best for RN devs:
1. A demo video / screen recording of your best app (native upload).
2. App Store / Play Store link or portfolio site.
3. Your best-performing technical post or carousel.
4. A case-study (GitHub README or blog) of a hard problem.
5. Resume PDF (optional; some prefer to send on request).

## 8. Recommendations

Ask 2–3 people (a manager, a PM/designer, a peer). Make it easy: send them 2 bullet points of specifics you'd love them to mention ("the offline sync rewrite", "how I unblocked QA with Detox"). Return the favor.

## 9. Other sections worth filling

- **Projects:** each with link + 1-line impact.
- **Licenses & certs:** only relevant ones (e.g., Meta React Native cert, AWS) — low weight, don't over-invest.
- **Services / Creator mode-like settings:** set "Topics" to React Native, Mobile Development, TypeScript if available.
- **Languages:** if targeting international/remote roles.

## 10. Profile audit checklist (score 0–2 each, /20)

1. "React Native" in headline
2. Professional photo
3. Value-based banner
4. Custom URL
5. About: hook + numbers + keyword line + CTA
6. Every role has quantified bullets
7. ≥ 30 relevant skills, top 5 pinned & endorsed
8. Featured has ≥ 3 proof items incl. a demo
9. Open to Work configured
10. ≥ 2 recommendations; activity in last 7 days
