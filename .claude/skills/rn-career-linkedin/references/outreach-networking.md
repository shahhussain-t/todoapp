# Outreach, Referrals & Networking

Reported response-rate ranges (2026 practitioner data, directional):
- Cold, templated LinkedIn message: ~5–15%
- Personalized message to the hiring manager: ~20–30%
- Warm intro / referral ask via a mutual or alumni: ~40–60%

**So: referrals and hiring managers first, cold apply second.** Apply AND message — they're complementary.

## Who to contact (per target company)
1. **Hiring manager** (Mobile Lead / Engineering Manager, Mobile) — search "mobile" + company, or check who posted the job.
2. **An RN/mobile engineer on the team** — for a referral or a 15-min chat.
3. **Technical recruiter** for that company.
4. **Alumni / ex-colleagues** at the company (filter People by school/past company).

## Rules
- < 100 words (connection notes: < 200–300 chars).
- First line is personal and specific (their post, their app, their talk, a shared thing).
- One clear, low-friction ask.
- Include proof link (app/portfolio) — but in DMs, not in your public posts' body.
- Follow up once after 4–7 days; then stop.
- Engage with their content for a week before asking, when possible.

## Templates

### Connection note to an engineer (referral path)
```
Hi Sara — loved your post on moving [Company]'s app to Expo Router. I'm a React Native dev (4 yrs, TS/Expo) and I'm applying for the Mobile Engineer role. Would you be open to a quick chat about the team?
```

### Referral ask (after connecting / some rapport)
```
Hi Sara, thanks for connecting! I've applied for the Senior React Native Engineer role (job ID 1234).
Quick fit: 4 yrs RN + TypeScript, shipped 5 apps (largest 250K MAU), led our New Architecture migration (cold start −38%).
If you think I'd be a fit, would you be comfortable referring me? I've attached a 3-line blurb + resume so it takes 30 seconds. Totally fine if not!
```
(Attach: resume PDF + 3-line blurb they can paste into the referral form.)

### Hiring manager
```
Hi Alex — I've been using [App] for months; the new onboarding animation is great. I saw you're hiring a React Native engineer. I recently shipped [project] (Reanimated + Expo Modules, demo: [link]) and cut cold start 40% at [Company]. Would a 15-min chat make sense this week or next?
```

### Recruiter
```
Hi Priya — I'm a React Native engineer (5 yrs, TypeScript, Expo/EAS, native modules) open to [remote/city] roles. I noticed [Company] has a Mobile Engineer opening — I've applied (ID 1234). Resume + portfolio: [link]. Happy to share more if helpful.
```

### Follow-up (once)
```
Hi Alex, quick nudge on this — I know inboxes get busy. Since I wrote, I shipped [new thing] ([link]). Still very interested in the role.
```

### After an interview / rejection (keep the door open)
```
Thanks again for the conversation, Alex. I enjoyed learning about [X]. If anything opens up on the mobile team in the future, I'd love to be considered — I'll keep following [Company]'s work.
```

## Networking habits
- Weekly: 10–20 personalized connection requests to mobile engineers/hiring managers/recruiters in target companies.
- Daily: 3–5 thoughtful comments (see content playbook).
- Monthly: 1 meetup/online event (React Native meetups, App.js, React Native EU, Expo community Discord) — post 3 takeaways after.
- Keep a simple tracker: company, role, contact, date, status, next step.

## Scam awareness
Fake recruiters target Open-to-Work profiles: never pay, never install unknown "assessment" apps or run repos from strangers on your main machine (malware via fake take-homes has been reported), verify email domains, and be suspicious of chat-only interviews.
